# Videos Directory

Place your hero background video here as `hero-background.mp4`.

The video should be:
- Format: MP4
- Optimized for web (compressed)
- Recommended resolution: 1920x1080 or 1280x720
- Loop-friendly content (seamless loop)
- Duration: 10-30 seconds for optimal performance

Example video sources:
- Stock video websites (Pexels, Pixabay)
- Custom footage
- Animated backgrounds

Current usage:
- Used in HeroSection component as background video
- Autoplay, muted, loop enabled for performance
