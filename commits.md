# Commandes

## Premières modifications

1- Initialiser le repository :
`git init`

2- Ajouter le sfichiers :
`git add .`

3- Effectuer le commit :
`git commit -m "message du commit"`

4- Créer une branche principale locale :
`git branch -M main`

5- Ajouter le remote distant :
`git remote add origin https://github.com/kephrr/dmplus-group.git`

6- Pousser le commit sur le remote distant sur la bonne branche
 
`git push origin main:distribution --force`
